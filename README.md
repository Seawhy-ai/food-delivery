# 袋鼠外卖 · 美团风格外卖点餐 Demo

一个**零依赖、零构建**的单文件外卖应用（`index.html` 约 4150 行）。视觉与信息架构参考美团外卖 App 的设计语言，**界面元素全部用手写 SVG 绘制**（30 个线性图标 + 28 种参数化食物插画），文件内不含任何 emoji 或外链图片资源。

> 纯前端演示：数据为本地静态模拟数据，**没有后端、没有真实交易**，下单只在本地 `localStorage` 生成一条模拟订单。

## 视觉系统（SVG 插画 + 真实照片双层）

早期版本用 emoji 当图标和菜品图，观感廉价且跨平台渲染不一致。现在的结构是**两层**：

**第一层：真实食物照片与本地生成商品图。** 常规菜品使用核对过的 Unsplash 直链图；10 家品牌茶饮店的菜单使用本地生成的商品级饮品图精灵，避免通用图库照片与菜单口味不匹配。

**第二层：SVG 兜底。** 30 个线性图标（`<symbol>` 雪碧图 + `<use>`，`stroke: currentColor` 继承文字色）+ 28 种参数化食物插画（`ART[kind](容器色, 食物色)`，`shade()` 从一个主色派生四档明暗）。照片挂了会被捕获阶段的 `error` 监听移除，自动露出下面的插画——所以**断网也不开天窗**。

| 层 | 实现 | 数量 |
|---|---|---|
| 商品图 | Unsplash 实拍 + 本地生成茶饮精灵图，懒加载 / cover / 失败回退 | 127+ |
| 线性图标 | `<symbol>` 雪碧图，`currentColor` | 30 个 |
| 食物插画 | 参数化 SVG，双色调 + 自动派生层次 | 28 种 |

插画覆盖了麻辣烫锅、面碗、盖饭、寿司、刺身、汉堡、炸鸡桶、薯条、烤串、铁板烧、蛋糕、咖啡、饮品、饺子、蔬菜、蒸蛋、葡萄、水果、西瓜切面、奇异果切面、易拉罐、瓶装水、零食袋、抽纸盒、电池、超市提篮等。**每个菜品由 `art: [类型, 容器色, 食物色]` 三个字段描述**，所以同一类插画也能靠配色区分（例如三款面条分别是红棕/番茄/麻辣色）。

调色不是手写的：`mkPal(hex)` 用 `shade()` 从一个主色派生出 `dark / deep / light / tint` 四档，插画只引用这些语义色，换个主色整张图自动协调。

> 唯一没有实拍图的是「电池 5 号 8 粒」——试了几批 Unsplash ID 和 Wikimedia Commons 都没找到合适的产品照，索性保留 SVG 插画，并在 `IMG` 表里留了注释说明这是有意的。

图标同理靠 `stroke: currentColor` 继承文字颜色，深色模式不用单独出一套图。

## 设计语言（对齐美团）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--mt-yellow` | `#FFD100` | 美团黄，主色（按钮、选中态、骑手头像） |
| `--mt-yellow-grad` | `#FFE566 → #FFD100 → #FFBE00` | 首页 / 商家页顶部渐变 |
| `--mt-black` | `#111111` | 近黑，底部购物车栏、搜索按钮、激活态 |
| `--mt-red` | `#E60012` | 价格、满减、红包 |
| `--mt-yellow-soft` | `#FFF3B0` | 标签底色 |

金刚区 10 个入口使用**手绘彩色扁平小图标**（KICO 雪碧集：奶茶杯、面碗、店铺、水果、红包、奖杯、摩托……每个 2-4 种色块，非纯线条），底色用 `--k` 变量 `color-mix` 出浅色底，选中态描边强调，布局整齐、图标清晰，对齐美团金刚区的设计语言。

**首页信息架构**（与美团一致的自上而下顺序）：

```
定位栏（当前收货地址）
  └ 搜索框（带满减利益点文案）
      └ 金刚区 10 个入口
          └ 瓷片区 3 个活动卡
              └ 排序筛选条（综合 / 销量 / 距离 / 评分）
                  └ 商家列表卡片（插画 · 评分 · 月售 · 时长 · 满减 · 起送价 · 配送费 · 打包费）
                      └ 底部固定 Tab（首页 / 订单 / 我的）
```

**商家页**采用外卖 App 标配的**左侧分类栏 + 右侧菜品列表**两栏结构，滚动时分类自动联动高亮，底部是常驻购物车栏（含数量角标、差 X 元起送提示）。

## 双击放大 Bug 的修复

移动端双击屏幕页面会放大，根因是**全文件没有声明 `touch-action`**，浏览器走了默认的双击缩放行为。

```css
html, body, .app, button, [data-action], [data-go], .tab, .shop-card, .kk-item,
.menu-row, .row, .tile, .dish-cat, .step-btn, .cart-ico-wrap, .search-bar {
    touch-action: manipulation;
}
```

`touch-action: manipulation` **只禁用双击缩放，保留平移和捏合缩放**——所以没有用 `user-scalable=no`，那会同时废掉视障用户的捏合缩放能力，是无障碍反模式。

配套还加了 `user-select: none`，否则桌面端双击卡片会选中一串文字，观感同样很差：

```css
button, .kk-item, .shop-card, .tab, .step-btn, .cart-ico-wrap, .menu-row, ...
    { -webkit-user-select: none; user-select: none; }
```

两条规则都写进了测试断言，防止以后改样式时被误删。

## 功能

### 浏览与发现
- **金刚区筛选** — 按品类过滤商家，选中态高亮，10 个入口各带专属强调色
- **四维排序** — 综合（评分与销量加权）/ 销量 / 距离 / 评分
- **搜索** — 匹配商家名、商家描述、菜品名、菜品描述、菜品分类；命中时在卡片下方高亮「匹配菜品」
- **搜索联想** — 输入即出菜品联想下拉（名称 + 价格），点击直接搜索；只更新联想层，不打断输入
- **热门搜索 + 搜索历史**（历史持久化，可一键清空）

### 商家与购物车
- 商家页 **点菜 / 评价 双 Tab**
- 两栏菜品浏览，分类栏显示该分类的**已选件数角标**
- **菜品规格** — 12 道菜配了规格组（规格 / 加料 / 辣度 / 温度 / 甜度 / 套餐），点「+」先弹规格面板，选完再入车；价格随规格实时联动；无规格的菜品点「+」直接加购
- 加减菜品**局部更新**，不重绘整个菜单（保住滚动位置与焦点）
- 底部购物车栏：数量角标、实时金额、差 X 元起送、**凑单提示（再买 X 元可减 Y）**、未达起送价时按钮禁用
- 上拉式购物车抽屉：按规格分行展示、继续加减、一键清空
- **单店下单约束**：跨店加购时弹出确认框，确认后清空原购物车（与美团行为一致）

### 结算与订单
- 收货地址选择（面板内可直达地址管理）、送达时间（尽快 / 指定时段）、订单备注
- **领券中心** — 深色英雄区统计 + 8 个分类筛选（含「团购」标签）+ 领取进度条 + 剩余张数；券池含美食/甜品/超市/免运费/会员专享 5 类 30 张（含抽奖红包与 10 张**商家专属券**，卡面带「门店券」徽标）；会员专享券需开通会员后领取
- **会员体系** — 会员中心（权益展示/开通/到期/关闭续费）、会员自动免配送费、会员专享券、会员徽标、开通扣减余额
- **余额支付** — 结算页可开关，自动按可用余额抵扣，实付 = 商品 + 打包 + 配送 − 满减 − 红包 − 余额
- **费用明细**：商品小计 + 打包费（按件）+ 配送费 − 满减（按最高档）− 红包 − 余额 = 实付
- 下单成功页（订单号 + 预计送达 + 小票）
- **订单中心**：全部 / 进行中 / 已完成三档筛选；订单详情含**四段进度时间轴**、骑手卡片、费用明细、再来一单
- **订单状态随时间推进**：待接单 → 已接单 → 骑手取货 → 已送达（按下单时间自动推进，刷新列表即更新）
- **订单操作**：进行中可取消，已完成可删除记录、去评价、再来一单

### 评价与收藏
- **评价系统** — 已完成订单可打星、选标签、写文字；评价写入订单并**汇入商家评价流**，商家评分按「基础分 3 : 用户评分 1」加权
- **商家页评价 Tab** — 展示种子评价 + 用户评价，头部显示平均分与总条数
- **收藏商家** — 商家页右上角心形收藏，收藏页集中管理，卡片带「已收藏」标记

### 地图 · 团购 · 抽奖
- **配送地图（集成订单详情）** — 独立地图页已移除，高德 Web 瓦片（免 Key）直接嵌入订单详情：商家标记使用**真实品牌坐标与品牌色**，显示品牌店名标签，与收货地址标记、虚线路线、骑手脉冲组成完整的配送视图；瓦片加载失败自动回退手绘 SVG 路线图
- **品牌奶茶店** — 新增霸王茶姬、喜茶、奈雪的茶、蜜雪冰城、茶百道、古茗、沪上阿姨、书亦烧仙草、CoCo都可、一点点共 10 家真实品牌（55 道真实菜品与贴近门店的价格：蜜雪 3-7 元、古茗 12-18 元、喜茶 16-29 元）。55 道饮品按口味映射到本地生成的商品级茶饮图，封面照与地图坐标齐备。
- **最优券置顶** — 结算自动按抵扣金额选中最优红包（「最优」徽标 + 默认选中），红包面板按可用性 + 抵扣金额降序排列；商家券跨店自动失效，「不使用红包」后不再自动替用户选择

### 其他
- **领券中心** — 集中领取红包，领取后进入「我的红包」
- **消息中心** — 红包过期、配送进度、活动通知

- 地址管理：设为默认、删除、新增（手机号正则校验、自动脱敏存储）
- 可访问性：语义化标签、`aria-label` / `aria-modal` / `aria-live` / `aria-pressed`、ESC 与遮罩点击关闭弹层、焦点样式

## 实现要点

- **事件委托 + 动作表**：所有交互走 `data-action` 属性，点击时分发到动作表。动作表用 `makeActions(el)` **按次构造**，`el` 作为闭包参数绑定 —— 否则异步回调（如确认弹窗的 `.then`）执行时，共享变量已被后续点击覆盖成 `null`。
- **全部插值经 `esc()` 转义**：即使之后把静态数据换成真实接口，也不会引入 XSS。
- **局部更新优先**：加减菜品只改数量文本与分类角标，不重建 DOM。
- **持久化数据带校验**：`loadState()` 会丢弃已下架的菜品 id 与非法数量，脏数据不会把 UI 带崩。
- **单点吸附**：首页让黄色头部随页面滚走、排序条吸附顶端；订单页同理。避免两个 `position: sticky; top: 0` 元素互相覆盖。

## 已知限制

- 无后端、无鉴权、无支付，下单不会产生真实订单。
- 优惠券、会员、团购、抽奖、评价、退款均为本地模拟，无服务端链路。
- 地图使用高德 Web 瓦片直链（无需 Key），瓦片离线时回退为手绘 SVG 路线图。
- 无构建流程与类型检查，正确性由 `node --check` + jsdom 冒烟测试（223 项）保证。
